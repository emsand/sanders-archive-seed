# sanders-archive-seed

The part of the offline archive only a Claude session can produce: the Claude-artifact snapshots (90-Claude-Artifacts/),
the Posting Desk export, the per-brand posting CSVs, SCHEDULE.md and SEED-VERSION.txt. Written by
`node tools/offline-archive/build-seed.mjs --seed-repo <this clone>` in emsand/daily-lessons-for-kids; the PC's refresh
(Build-OfflineArchive.ps1, config seedRepo) clones/pulls this repo and lays it over the archive root. Private. Last build 2026-09-17.
